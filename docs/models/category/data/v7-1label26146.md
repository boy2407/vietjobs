# Data — category @ v7-1label26146

One row per distinct key (lowercase, no punctuation, no whitespace over the BERT input; Vietnamese diacritics kept). Every text that appears with two or more labels is **dropped**, not given a label: 34,742 distinct texts → **26,146**, dropping 8,596. Re-split with the same two-stage algorithm and seed (8:2, then 9:1), each text its own unit → `data/processed/splits-dedup-norm-1label/`, which keeps the 18 raw columns as `raw_*`. The procedure is in `cach-xet-trung.md`.

Scope: three text columns, the label, and the 18 raw columns for slices. All splits read for counts and cross-split duplicate checks only; no manual look at `test`. MinHash ran with `datasketch` 2.0.0, installed in `.venv` (not added to `requirements.txt`).
